Activity 6.3.1. Swerving, Backed by a Threat.

The two teenagers play Chicken over and over, in rounds \(k = 0, 1, 2, \ldots\text{,}\) with discount factor \(\delta\text{,}\) where \(0 \lt \delta \lt 1\text{.}\) Consider the following strategy, which we’ll call \(\gamma\text{:}\)
🔗
  • Swerve as long as both teenagers have swerved in every earlier round.
    🔗
    🔗
  • If either teenager has ever gone straight, go straight in every round from then on.
    🔗
    🔗
This is Chicken’s version of the trigger strategy: the threat is “if anyone goes straight, we crash every round from now on.” We’ll show that \((\gamma, \gamma)\) is a Nash equilibrium when \(\delta \geq \frac{1}{2}\text{,}\) following the same steps as the proof of Theorem 6.1. Suppose Teenager 1 uses \(\gamma\text{,}\) and we’ll check whether Teenager 2 can do better by switching to a different strategy.
🔗

(a)

Suppose both teenagers use \(\gamma\text{.}\) Fill in the table below, and find \(\pi_2(\gamma, \gamma)\text{.}\)
🔗
round 0 round 1 round 2 round 3 \(\cdots\)
Teenager 1’s move \(\cdots\)
Teenager 2’s move \(\cdots\)
Teenager 2’s payoff \(\cdots\)
Solution.
Nobody ever goes straight first, so both swerve in every round:
🔗
round 0 round 1 round 2 round 3 \(\cdots\)
Teenager 1’s move swerve swerve swerve swerve \(\cdots\)
Teenager 2’s move swerve swerve swerve swerve \(\cdots\)
Teenager 2’s payoff \(0\) \(0\) \(0\) \(0\) \(\cdots\)
Teenager 2 gets 0 every round, so \(\pi_2(\gamma, \gamma) = 0\text{.}\)
🔗
🔗
🔗

(b)

Now suppose Teenager 1 keeps using \(\gamma\text{,}\) but Teenager 2 switches to some other strategy, \(\gamma'\text{.}\) First, suppose \(\gamma'\) never goes straight. What happens in every round? What is \(\pi_2(\gamma, \gamma')\text{?}\) Does Teenager 2 do any better than with \(\gamma\text{?}\)
🔗
Solution.
Teenager 2 swerves in every round, so nobody ever goes straight, and \(\gamma\) tells Teenager 1 to swerve in every round too. Both swerve forever, just as with \((\gamma, \gamma)\text{,}\) so \(\pi_2(\gamma, \gamma') = 0 = \pi_2(\gamma, \gamma)\text{.}\) Teenager 2 does no better.
🔗
🔗
🔗

(c)

Otherwise, \(\gamma'\) goes straight at some point. Say Teenager 2 goes straight for the first time in round \(k\text{.}\) Then:
🔗
  • In rounds 0 through \(k-1\text{,}\) nobody has gone straight, so both teenagers swerve.
    🔗
    🔗
  • In round \(k\text{,}\) Teenager 1 still swerves, since nobody had gone straight before round \(k\text{,}\) and Teenager 2 goes straight.
    🔗
    🔗
Fill in the rest of the table, assuming that from round \(k+1\) on, Teenager 2 makes their best move in every round.
🔗
round 0 \(\cdots\) round \(k-1\) round \(k\) round \(k+1\) round \(k+2\) \(\cdots\)
Teenager 1’s move (\(\gamma\)) swerve swerve \(\cdots\)
Teenager 2’s move (\(\gamma'\)) swerve straight \(\cdots\)
Teenager 2’s discounted payoff \(0\) \(\delta^k\) \(\cdots\)
Hint.
From round \(k+1\) on, Teenager 2 has gone straight, so \(\gamma\) tells Teenager 1 to go straight in every round, no matter what Teenager 2 does. What is Teenager 2’s best response to a teenager who goes straight?
🔗
🔗
Solution.
From round \(k+1\) on, Teenager 1 goes straight in every round. Against that, Teenager 2 gets \(-1\) by swerving and \(-2\) by going straight, and nothing Teenager 2 does can change Teenager 1’s later moves. So Teenager 2’s best move is to swerve in every round, for \(-1\) each round:
🔗
round 0 \(\cdots\) round \(k-1\) round \(k\) round \(k+1\) round \(k+2\) \(\cdots\)
Teenager 1’s move (\(\gamma\)) swerve swerve straight straight \(\cdots\)
Teenager 2’s move (\(\gamma'\)) swerve straight swerve swerve \(\cdots\)
Teenager 2’s discounted payoff \(0\) \(\delta^k\) \(-\delta^{k+1}\) \(-\delta^{k+2}\) \(\cdots\)
This is different from the Wine Merchant game. There, after Bernard defected, his best move was to keep defecting. Here, after Teenager 2 goes straight once, their best move is to go back to swerving.
🔗
🔗
🔗

(d)

Using the tables, here are Teenager 2’s payoffs for the two strategies:
\begin{align*} \pi_2(\gamma, \gamma) \amp = \underbrace{0 + 0 + \cdots + 0}_{\text{rounds } 0 \text{ to } k-1} + 0 + 0 + 0 + \cdots\\ \pi_2(\gamma, \gamma') \amp = \underbrace{0 + 0 + \cdots + 0}_{\text{rounds } 0 \text{ to } k-1} + \delta^k - \delta^{k+1} - \delta^{k+2} - \cdots \end{align*}
The terms for rounds 0 through \(k-1\) are the same, so we are really comparing
\begin{equation*} 0 + 0 + 0 + \cdots = 0 \qquad \text{with} \qquad \delta^k - \delta^{k+1} - \delta^{k+2} - \cdots. \end{equation*}
Find the sum \(\delta^k - \delta^{k+1} - \delta^{k+2} - \cdots\text{.}\)
🔗
Hint.
After the first term, the rest is a geometric series: \(-\delta^{k+1} - \delta^{k+2} - \cdots\) has \(a = -\delta^{k+1}\) and \(r = \delta\text{.}\)
🔗
🔗
Solution.
The only positive term is the first one, from round \(k\text{.}\) Everything after it is a geometric series:
\begin{equation*} \delta^k - \delta^{k+1} - \delta^{k+2} - \cdots = \underbrace{\delta^k}_{\text{round } k} + \underbrace{\left(-\delta^{k+1} - \delta^{k+2} - \cdots\right)}_{a = -\delta^{k+1},\ r = \delta}. \end{equation*}
So
\begin{equation*} \delta^k - \delta^{k+1} - \delta^{k+2} - \cdots = \delta^k - \frac{\delta^{k+1}}{1 - \delta}. \end{equation*}
🔗
🔗
🔗

(e)

Going straight in round \(k\) does not help Teenager 2 when \(\pi_2(\gamma, \gamma') \leq \pi_2(\gamma, \gamma)\text{,}\) that is, when
\begin{equation*} \delta^k - \frac{\delta^{k+1}}{1 - \delta} \leq 0. \end{equation*}
For which values of \(\delta\) is this true? Conclude that \((\gamma, \gamma)\) is a Nash equilibrium for those values of \(\delta\text{.}\)
🔗
Hint.
Divide both sides by \(\delta^k\text{,}\) just as in the proof of Theorem 6.1.
🔗
🔗
Solution.
Dividing by \(\delta^k\) gives \(1 - \frac{\delta}{1 - \delta} \leq 0\text{.}\) Multiplying by \(1 - \delta\text{,}\) which is positive, gives \(1 - \delta - \delta \leq 0\text{,}\) so \(\delta \geq \frac{1}{2}\text{.}\)
🔗
So when \(\delta \geq \frac{1}{2}\text{,}\) no strategy \(\gamma'\) gives Teenager 2 more than \(\pi_2(\gamma, \gamma)\text{:}\) if \(\gamma'\) never goes straight, Teenager 2 gets the same payoff, and if it first goes straight in round \(k\text{,}\) the best Teenager 2 can do is the payoff we just found, which is at most 0. So \(\gamma\) is a best response to \(\gamma\text{.}\) By symmetry, the same is true for Teenager 1, so \((\gamma, \gamma)\) is a Nash equilibrium when \(\delta \geq \frac{1}{2}\text{.}\)
