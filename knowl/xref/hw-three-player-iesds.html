Exercise 2. A Three Player Game in Normal Form.

In this exercise, we consider a three player game in normal form where each player has two strategies \(A\) and \(B\text{.}\) That is, \(S_i = \{A, B\}\) for each player \(i\text{.}\)
🔗
We can represent such a game using two tables: one for when player 3 plays \(A\text{,}\) and a second for when player 3 plays \(B\text{.}\) These tables are shown below, with payoffs listed in the usual order, (player 1, player 2, player 3).
🔗
This is a single normal form game represented using two tables. These are not two separate games.
🔗
Analyze this game using iterated elimination of strictly dominated strategies. Be sure to state the order in which strategies are eliminated. If you find a dominant strategy equilibrium, state that equilibrium.

Hint.
When stating a dominant strategy equilibrium, we need to state the strategy profile. The strategy profile determines the payoffs, but it is not equivalent to the payoffs.
