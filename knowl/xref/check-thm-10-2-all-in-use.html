Checkpoint 10.3.2.

Suppose every strategy is active at \(\sigma\) (all \(p_i \gt 0\)). Which statement is true?
🔗
  • \(\sigma\) is an equilibrium if and only if \((\sigma, \sigma)\) is a Nash equilibrium.
  • Right. Condition (2) of Theorem 5.2 is about inactive strategies, and here there are none. So a Nash equilibrium only needs condition (1), which is exactly what Theorem 10.2 requires for an equilibrium.
  • \(\sigma\) can be an equilibrium without \((\sigma, \sigma)\) being a Nash equilibrium.
  • Not quite. That can only happen if condition (2) fails, which needs an inactive strategy that does better. Here every strategy is active.
  • \((\sigma, \sigma)\) can be a Nash equilibrium without \(\sigma\) being an equilibrium.
  • Not quite. A Nash equilibrium satisfies condition (1), so by Theorem 10.2 it is always an equilibrium.
