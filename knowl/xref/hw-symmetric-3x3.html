This game is symmetric: if the players swap strategies, they also swap payoffs. So you only need to do the computation for one player, and you get a symmetric Nash equilibrium \((\sigma, \sigma)\text{,}\) where both players use the same mixed strategy \(\sigma = xa + yb + zc\text{.}\)
🔗

(a)

Use the Fundamental Theorem of Nash Equilibria to set up a system of linear equations whose solution gives a symmetric Nash equilibrium \((\sigma, \sigma)\) in which all three strategies are active. Explain where each equation comes from.
🔗
Solution.
\begin{align*} 2x + 6y + 5z = 3x + 3y + 9z \amp = 4x + 4y + 7z\\ x + y + z \amp = 1 \end{align*}
