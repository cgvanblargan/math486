    1. Hawk and Dove.

    (a) The two inequalities in payoff notation.

    Use payoff notation to state the two inequalities required for \(d\) to be strictly dominated by \(h\) for player 1.
    🔗
    Solution.
    • \(\pi_1(h,h) \gt \pi_1(d,h)\text{,}\) which is \(\dfrac{v-w}{2} \gt 0\text{,}\) which simplifies to \(v \gt w\text{.}\)
      🔗
      🔗
    • \(\pi_1(h,d) \gt \pi_1(d,d)\text{,}\) which is \(v \gt \dfrac{v}{2}\text{,}\) which simplifies to \(v \gt 0\text{.}\)
      🔗
      🔗
    🔗
    🔗

    (b) When \(h\) strictly dominates \(d\).

    Find all \(v \gt 0\) for which \(d\) is strictly dominated by \(h\text{.}\)
    🔗
    Solution.
    \(v \gt w\text{.}\)
    🔗
    🔗
    🔗

    (c) When nothing is dominated.

    Find all \(v \gt 0\) for which the game has no dominated strategy, strictly or weakly.
    🔗
    Solution.
    \(0 \lt v \lt w\text{.}\)
    🔗
    🔗
    🔗

    (d) When the dominance is weak but not strict.

    Find all \(v \gt 0\) for which some strategy is weakly but not strictly dominated, and say which one.
    🔗
    Solution.
    \(v = w\text{;}\) \(d\) is weakly dominated by \(h\text{.}\)

    3. The Common Pasture.

    (a) The two payoff functions.

    Determine \(\pi_i(R, m)\) and \(\pi_i(I, m)\text{.}\)
    🔗
    Solution.
    \begin{align*} \pi_i(R, m) \amp = pk - m\,\frac{c}{N},\\ \pi_i(I, m) \amp = p(k+1) - (m+1)\frac{c}{N}. \end{align*}
    Playing \(I\) adds player \(i\)’s own extra cow to the excess, which is why the cost term counts \(m+1\) rather than \(m\text{.}\)
    🔗
    🔗
    🔗

    (b) \(I\) strictly dominates \(R\).

    Use the payoffs to prove that \(R\) is strictly dominated by \(I\text{.}\)
    🔗
    Solution.
    Fix any \(m\) and regroup so that \(\pi_i(R,m)\) appears inside \(\pi_i(I,m)\text{:}\)
    🔗
    \begin{equation*} \pi_i(I,m) = p(k+1) - (m+1)\frac{c}{N} = \underbrace{\left[\,pk - m\,\frac{c}{N}\,\right]}_{\pi_i(R,m)} \;+\; \underbrace{\left(p - \frac{c}{N}\right)}_{\gt\; 0 \text{ since } \frac{c}{N} \,\lt\, p} \end{equation*}
    So \(\pi_i(I,m) \gt \pi_i(R,m)\) for every \(m\text{.}\)
    🔗
    🔗
    🔗

    (c) Everyone irresponsible versus everyone responsible.

    Compare the payoff when all play \(I\) with the payoff when all play \(R\text{.}\)
    🔗
    Solution.
    All \(R\) gives \(m = 0\) and \(\pi_i(R,0) = pk\text{.}\) All \(I\) gives \(m = N-1\text{,}\) and grouping the same way:
    🔗
    \begin{equation*} \pi_i(I, N-1) = p(k+1) - N\cdot\frac{c}{N} = \underbrace{\vphantom{\Big[}\;pk\;}_{\pi_i(R,\,0)} \;+\; \underbrace{\vphantom{\Big[}\;(p - c)\;}_{\lt\; 0 \text{ since } p \,\lt\, c} \end{equation*}
    Every player is \(c - p\) worse off than under all \(R\text{.}\)
    🔗
    🔗
    🔗

    (d) Comparison with the prisoner’s dilemma.

    How does this game compare with the prisoner’s dilemma?
    🔗
    Solution.
    It is an \(N\)-player prisoner’s dilemma, with both defining features: every player has a strictly dominant strategy \(I\text{,}\) so \((I,\ldots,I)\) is a dominant strategy equilibrium; and that equilibrium is worse for every player, by \(c-p\) each, than the profile \((R,\ldots,R)\) built from the dominated strategies. Same asymmetry as the global warming game of Section 2.5: a player collects the whole benefit of the extra cow but pays only \(\tfrac{1}{N}\) of the cost it creates.
    🔗
    🔗
    🔗
    🔗

    4. Locating Two Banks.

    (a) \(s_A = 2\) is not dominated by \(s_A = 3\).

    Exhibit a choice by \(B\) under which \(A\) does strictly better at block 2 than at block 3.
    🔗
    Solution.
    Take \(s_B = 1\text{.}\) Then \(s_A = 2\) gives \(A\) blocks 2 through 99, for \(9800\text{,}\) while \(s_A = 3\) gives blocks 3 through 99 plus half of block 2, for \(9750\text{.}\) One such column is all the definition requires, so \(s_A = 2\) is not dominated by \(s_A = 3\text{.}\)
    🔗
    Worth noting for part (c): \(s_B = 1\) is the only column where block 2 wins.
    🔗
    🔗
    🔗

    (b) \(s_A = 1\) is strictly dominated by \(s_A = 2\).

    Show the domination in the three cases, then give the correspondence that converts the argument into the one for \(s_i = 99\) against \(s_i = 98\text{.}\)
    🔗
    Solution.
    • \(s_B = 1\text{:}\) \(s_A = 1\) gives \(4950\text{;}\) \(s_A = 2\) gives \(9800\text{.}\)
      🔗
      🔗
    • \(s_B = 2\text{:}\) \(s_A = 1\) gives \(100\text{;}\) \(s_A = 2\) gives \(4950\text{.}\)
      🔗
      🔗
    • \(s_B \geq 3\text{:}\) switching from \(s_A = 1\) to \(s_A = 2\) gives an improvement of \(50\text{.}\)
      🔗
      🔗
    \(s_A = 2\) wins all three, so \(s_A = 1\) is strictly dominated by \(s_A = 2\text{.}\)
    🔗
    The correspondence. Relabel block \(i\) as block \(100 - i\text{,}\) reflecting the avenue end over end. It sends \(1 \mapsto 99\) and \(2 \mapsto 98\text{,}\) and maps \(\{1,\ldots,99\}\) onto itself. Payoffs are unaffected because every block still holds 100 residents and distances are preserved, \(|(100-i)-(100-j)| = |i-j|\text{.}\) So the three cases above become the three cases for \(s_i = 99\) against \(s_i = 98\text{.}\)
    🔗
    🔗
    🔗

    (c) After eliminating blocks 1 and 99.

    Explain why \(s_i = 2\) is now strictly dominated by \(s_i = 3\text{,}\) and why this does not contradict part (a).
    🔗
    Solution.
    With \(S_i = \{2,\ldots,98\}\text{,}\) shift the whole argument of part (b) one block to the right: the three cases for \(B\) become \(s_B = 2\text{,}\) \(s_B = 3\text{,}\) and \(s_B \geq 4\) (instead of \(1\text{,}\) \(2\text{,}\) and \(\geq 3\)), and in each case block 3 beats block 2 in the same way block 2 beat block 1. The reflection \(i \mapsto 100-i\) gives \(s_i = 98\) strictly dominated by \(s_i = 97\text{,}\) and by symmetry all of this holds for \(B\) too.
    🔗
    What changed since part (a). The only column favoring block 2 was \(s_B = 1\text{,}\) which is no longer one of \(B\)’s strategies.
    🔗
    🔗
    🔗

    (d) The reduced game \(S_i = \{49, 50, 51\}\).

    Check that \(s_i = 49\) and \(s_i = 51\) are strictly dominated by \(s_i = 50\text{,}\) with explicit computations for \(s_A = 49\text{.}\)
    🔗
    Solution.
    \(s_A = 49\) against \(s_A = 50\text{:}\)
    🔗
    • \(s_B = 49\text{:}\) \(s_A = 49\) gives \(4950\text{;}\) \(s_A = 50\) gives \(5000\text{.}\)
      🔗
      🔗
    • \(s_B = 50\text{:}\) \(s_A = 49\) gives \(4900\text{;}\) \(s_A = 50\) gives \(4950\text{.}\)
      🔗
      🔗
    • \(s_B = 51\text{:}\) \(s_A = 49\) gives \(4950\text{;}\) \(s_A = 50\) gives \(5000\text{.}\)
      🔗
      🔗
    \(s_A = 51\) against \(s_A = 50\text{:}\)
    🔗
    • \(s_B = 49\text{:}\) \(s_A = 51\) gives \(4950\text{;}\) \(s_A = 50\) gives \(5000\text{.}\)
      🔗
      🔗
    • \(s_B = 50\text{:}\) \(s_A = 51\) gives \(4900\text{;}\) \(s_A = 50\) gives \(4950\text{.}\)
      🔗
      🔗
    • \(s_B = 51\text{:}\) \(s_A = 51\) gives \(4950\text{;}\) \(s_A = 50\) gives \(5000\text{.}\)
      🔗
      🔗
    \(s_A = 50\) wins every column in both comparisons, so \(s_A = 49\) and \(s_A = 51\) are strictly dominated by \(s_A = 50\text{.}\) By player symmetry the same holds for \(B\text{.}\)
    🔗
    🔗
    🔗

    (e) Is \((50,50)\) a dominant strategy equilibrium?

    Based on part (d), decide whether \((50,50)\) is a dominant strategy equilibrium of the original game.
    🔗
    Solution.
    Yes. Iterated elimination leaves each player exactly one strategy, \(s_i^* = 50\text{,}\) which is the definition.
    🔗
    🔗
    🔗

    (f) Does \(s_i = 50\) dominate everything from the start?

    In the original game, does \(s_i = 50\) strictly dominate every other strategy?
    🔗
    Solution.
    No. Against \(s_B = 1\text{,}\) block 2 gives \(9800\) while block 50 gives \(7400\text{,}\) so \(s_A = 50\) does not strictly dominate \(s_A = 2\text{.}\)
    🔗
    This is the caution from Section 2.8: a dominant strategy is whatever survives iterated elimination, which is not the same as beating every rival strategy in the original game.
