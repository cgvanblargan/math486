    Section 10.1 The Replicator System

    In this chapter, we continue to study evolutionary games, so we are dealing with a large population whose members play a symmetric two-player game against each other over and over. In Chapter 8, the population state \(\sigma\) was fixed, and we asked whether it was evolutionarily stable, that is, whether it could hold off a small group of invaders.
    🔗
    In this chapter, we model the population state as changing continuously over time. We will write the population state as a function of time:
    \begin{equation*} \sigma(t) = p_1(t)s_1 + p_2(t)s_2 + \cdots + p_n(t)s_n, \end{equation*}
    where \(p_i(t)\) is the fraction of the population using strategy \(s_i\) at time \(t\text{.}\) The state at the start is \(\sigma(0)\text{.}\)
    🔗
    This makes differential equations a natural model, and we can use the ideas from Chapter 9 to analyze their solutions and equilibria. If a strategy does well, you’d expect the portion of the population using it to increase with time. On the other hand, a strategy that doesn’t do well should die out! We will look for asymptotically stable equilibria that the population state approaches.
    🔗

    Section 10.1, Replicator System.

    Read Section 10.1.
    🔗
    In the reading, the following important ideas are introduced:
    • The replicator system (10.1) is the system of differential equations that models how the population state changes:
      \begin{equation*} \dot{p}_i = \bigl(\pi_1(s_i, \sigma) - \pi_1(\sigma, \sigma)\bigr)p_i, \qquad i = 1, \ldots, n. \end{equation*}
      🔗
      🔗
    • Theorem 10.1 lists some basic properties of the replicator system, about which sets of population states solutions stay in (invariance) and which states are always equilibria.
      🔗
      🔗
    Reading the proof of Theorem 10.1 will help you get acquainted with the concepts and notation, but it is not strictly required to get through the material.
    🔗
    🔗
    Let’s write down the important ideas from the reading for reference. We will use all of them throughout this chapter.
    🔗

    The replicator system.

    Here is the replicator system again, with the different parts labeled. (Note that in the replicator system, \(\sigma\text{,}\) \(p_i\text{,}\) and \(\dot{p}_i\) are all functions of time.)
    \begin{equation*} \underbrace{\dot{p}_i}_{\substack{\text{rate of change of}\\ \text{the share using } s_i}} \;=\; \underbrace{\bigl(\pi_1(s_i, \sigma) - \pi_1(\sigma, \sigma)\bigr)}_{\substack{\text{how much better } s_i \text{ does}\\ \text{than the population average}}} \; \underbrace{p_i}_{\substack{\text{current share}\\ \text{using } s_i}} \end{equation*}
    🔗
    Recall that \(\pi_1(s_i, \sigma)\) is the expected payoff to an individual using \(s_i\) against a random member of the population, and \(\pi_1(\sigma, \sigma)\) is the average payoff in the population. Both are computed using the current state \(\sigma = \sigma(t)\text{,}\) so as the population changes, the payoffs change too.
    🔗
    🔗

    Checkpoint 10.1.1.

    Using the labeled replicator system, which of the following statements are true? Select all that apply.
    🔗
    • If \(s_i\) does better than average, \(p_i\) increases.
    • True. The payoff advantage is positive and \(p_i \gt 0\text{,}\) so \(\dot{p}_i \gt 0\text{.}\)
    • If \(s_i\) does worse than average, \(p_i\) increases.
    • False. The payoff advantage is negative, so \(\dot{p}_i \lt 0\) and \(p_i\) decreases.
    • If \(s_i\) does exactly as well as average, or nobody uses it, \(p_i\) stays constant.
    • True. In the first case the payoff advantage is 0, and in the second case \(p_i = 0\text{.}\) Either way, \(\dot{p}_i = 0\text{.}\)
    🔗
    The book gives two ways to interpret this. In biology, strategies with higher payoffs have more offspring. In social situations, people see which strategies are succeeding and copy them.
    🔗

    The simplex and its strata.

    The replicator system only makes sense for population states, where every share is nonnegative and the shares add up to 1. This set is called the simplex:
    \begin{equation*} \Sigma = \Bigl\{(p_1, \ldots, p_n) : \text{all } p_i \geq 0 \text{ and } \sum p_i = 1\Bigr\}. \end{equation*}
    🔗
    The simplex is split into pieces called strata based on which strategies are actually in use. For a nonempty set \(I \subseteq \{1, \ldots, n\}\text{,}\) the stratum \(\Sigma_I\) contains the states where exactly the strategies with \(i \in I\) are used:
    \begin{equation*} \Sigma_I = \Bigl\{(p_1, \ldots, p_n) : p_i \gt 0 \text{ if } i \in I,\ p_i = 0 \text{ if } i \notin I, \text{ and } \sum p_i = 1\Bigr\}. \end{equation*}
    🔗
    Figure 10.1 gives a good visualization of the different strata for \(n = 3\text{.}\)
    🔗
    🔗
    Last, we restate Theorem 10.1 for reference, and then we’ll see a quick interpretation of each part!
    🔗

    Theorem 10.1.2 Theorem 10.1.

    The replicator system has the following properties:
    1. If \(p_i = 0\text{,}\) then \(\dot{p}_i = 0\text{.}\)
      🔗
      🔗
    2. Let \(S(p_1, \ldots, p_n) = \sum p_i\text{.}\) If \(S = 1\text{,}\) then \(\dot{S} = 0\text{.}\)
      🔗
      🔗
    3. Each stratum \(\Sigma_I\) is invariant.
      🔗
      🔗
    4. Each stratum \(\Sigma_{\{i\}}\) is an equilibrium.
      🔗
      🔗
    🔗
    🔗
    Here are ways to think about each part of the theorem:
    • (1) An inactive strategy stays inactive. The model has no mutation, so a new strategy can never appear on its own.
      🔗
      🔗
    • (2) The fractions of the population using each strategy always add up to 1. It’s good that this is true! Otherwise, \(\sigma(t)\) would stop being a legitimate population state.
      🔗
      🔗
    • (3) A solution never leaves the stratum it starts in. In particular, an active strategy never dies out completely in finite time. Its share can approach 0 as \(t \to \infty\text{,}\) but it never reaches 0.
      🔗
      🔗
    • (4) Note that \(\Sigma_{\{i\}}\) consists of just the pure state \(s_i\text{.}\) So this says every pure state, where the whole population uses one strategy, is an equilibrium. That is, if the initial population state uses only this pure strategy, it stays that way for all time! However, an equilibrium does not have to be stable: nearby solutions could move away from it. Deciding which equilibria are stable is a big part of this chapter.
      🔗
      🔗
    🔗

    Reducing the number of equations.

    The end of Section 10.1 points out that we don’t need all \(n\) equations. Since the shares add up to 1, we can use \(p_n = 1 - p_1 - \cdots - p_{n-1}\) and keep only the first \(n - 1\) equations. We will see this in the Microsoft vs. Apple example coming up!
    🔗
    🔗
    In Section 10.2, the book discusses an example: Microsoft vs. Apple. I have broken down the math in the following example block, with some dropdown solutions and checkpoint questions. You can read it in the book first if you like, but this breaks down the different steps, and some parts will have you thinking more actively about the example!
    🔗

    Example 10.1.3 Microsoft vs. Apple.

    In the early days of personal computers, you could buy a computer running Microsoft Windows or one running Apple’s operating system. Apple’s was better, but neither handled files from the other well, so if you and your coworker used different systems, not much got done. The strategies are buy Microsoft (\(m\)) or buy Apple (\(a\)):
    🔗
    This is case (3) of Theorem 8.5 (a game like Stag Hunt). As the book lists, there are three Nash equilibria:
    • \((m, m)\) and \((a, a)\text{,}\) which are strict, so the population states \(m\) and \(a\) are evolutionarily stable;
      🔗
      🔗
    • \((\sigma^*, \sigma^*)\) with \(\sigma^* = \frac{2}{3}m + \frac{1}{3}a\text{,}\) which is not evolutionarily stable.
      🔗
      🔗
    Now let’s see what the replicator system says. Write the population state as \(\sigma = p_1 m + p_2 a\text{,}\) so \(p_1\) is the share using Microsoft and \(p_2\) is the share using Apple.
    🔗

    (a) The payoffs.

    Find \(\pi_1(m, \sigma)\text{,}\) \(\pi_1(a, \sigma)\text{,}\) and \(\pi_1(\sigma, \sigma)\) in terms of \(p_1\) and \(p_2\text{.}\)
    🔗
    Solution.
    A Microsoft user gets 1 against another Microsoft user and 0 against an Apple user, so
    \begin{equation*} \pi_1(m, \sigma) = p_1 \cdot 1 + p_2 \cdot 0 = p_1. \end{equation*}
    An Apple user gets 0 against a Microsoft user and 2 against another Apple user, so
    \begin{equation*} \pi_1(a, \sigma) = p_1 \cdot 0 + p_2 \cdot 2 = 2p_2. \end{equation*}
    The average payoff weights each strategy’s payoff by its share:
    \begin{equation*} \pi_1(\sigma, \sigma) = p_1 \pi_1(m, \sigma) + p_2 \pi_1(a, \sigma) = p_1^2 + 2p_2^2. \end{equation*}
    🔗
    🔗
    🔗

    (b) The equation for \(\dot{p}_1\).

    Write the replicator equation for \(\dot{p}_1\text{.}\)
    🔗
    Solution.
    Plug the payoffs into \(\dot{p}_1 = \bigl(\pi_1(m, \sigma) - \pi_1(\sigma, \sigma)\bigr)p_1\text{:}\)
    \begin{equation*} \dot{p}_1 = \bigl(p_1 - (p_1^2 + 2p_2^2)\bigr)p_1. \end{equation*}
    🔗
    🔗
    🔗

    (c) The equation for \(\dot{p}_2\).

    Now try it yourself! Which of the following is the replicator equation for \(\dot{p}_2\text{?}\)
    🔗
    • \(\dot{p}_2 = \bigl(2p_2 - (p_1^2 + 2p_2^2)\bigr)p_2\)
    • Right. This is \(\bigl(\pi_1(a, \sigma) - \pi_1(\sigma, \sigma)\bigr)p_2\text{,}\) with \(\pi_1(a, \sigma) = 2p_2\text{.}\)
    • \(\dot{p}_2 = 2p_2 - (p_1^2 + 2p_2^2)\)
    • Not quite. This is the payoff advantage of \(a\text{,}\) but the replicator equation multiplies it by the current share \(p_2\text{.}\)
    • \(\dot{p}_2 = \bigl(p_1 - (p_1^2 + 2p_2^2)\bigr)p_2\)
    • Not quite. This uses \(\pi_1(m, \sigma) = p_1\text{,}\) the payoff to a Microsoft user. For \(\dot{p}_2\text{,}\) we need the payoff to an Apple user, \(\pi_1(a, \sigma) = 2p_2\text{.}\)
    • \(\dot{p}_2 = \bigl((p_1^2 + 2p_2^2) - 2p_2\bigr)p_2\)
    • Not quite. The subtraction is backward: this would make Apple shrink when it does better than average. The replicator equation uses the strategy’s payoff minus the average.
    🔗

    (d) Reducing to one variable.

    As we noted after Theorem 10.1, we only need one of these equations: since \(p_2 = 1 - p_1\text{,}\) knowing \(p_1(t)\) tells us \(p_2(t)\) too. Substitute \(p_2 = 1 - p_1\) into the equation for \(\dot{p}_1\) and factor it.
    🔗
    Solution.
    Start with the equation for \(\dot{p}_1\) and substitute \(p_2 = 1 - p_1\text{:}\)
    \begin{equation*} \dot{p}_1 = \bigl(p_1 - p_1^2 - 2p_2^2\bigr)p_1 = \bigl(p_1 - p_1^2 - 2\underbrace{(1 - p_1)^2}_{p_2 = 1 - p_1}\bigr)p_1. \end{equation*}
    We know in advance that \(1 - p_1\) must be a factor, since \(p_1 = 1\) is an equilibrium. To pull it out, notice that \(p_1 - p_1^2 = (1 - p_1)p_1\text{:}\)
    \begin{align*} \dot{p}_1 \amp = \bigl((1 - p_1)p_1 - 2(1 - p_1)^2\bigr)p_1\\ \amp = (1 - p_1)\bigl(p_1 - 2(1 - p_1)\bigr)p_1\\ \amp = p_1(1 - p_1)(3p_1 - 2). \end{align*}
    So the whole replicator system comes down to one autonomous differential equation,
    \begin{equation*} \dot{p}_1 = p_1(1 - p_1)(3p_1 - 2). \end{equation*}
    🔗
    🔗
    🔗

    (e) The equilibria.

    Now let’s find all the equilibria and draw the whole phase line.
    🔗
    Which values of \(p_1\) in \([0, 1]\) are equilibria of \(\dot{p}_1 = p_1(1 - p_1)(3p_1 - 2)\text{?}\) Select all that apply.
    🔗
    • \(p_1 = 0\)
    • Yes. This is the factor \(p_1\text{,}\) and it is the pure state where everyone uses Apple, which Theorem 10.1(4) says is always an equilibrium.
    • \(p_1 = \frac{1}{3}\)
    • No. At \(p_1 = \frac{1}{3}\text{,}\) the factor \(3p_1 - 2 = -1\text{,}\) so \(\dot{p}_1 \neq 0\text{.}\) (The equilibrium \(\sigma^*\) has \(p_2 = \frac{1}{3}\text{,}\) not \(p_1\text{.}\))
    • \(p_1 = \frac{1}{2}\)
    • No. At \(p_1 = \frac{1}{2}\text{,}\) the factor \(3p_1 - 2 = -\frac{1}{2}\text{,}\) so \(\dot{p}_1 \neq 0\text{.}\)
    • \(p_1 = \frac{2}{3}\)
    • Yes. This is where \(3p_1 - 2 = 0\text{.}\) It is also where both strategies earn the same payoff: \(\pi_1(m, \sigma) = p_1 = \frac{2}{3}\) and \(\pi_1(a, \sigma) = 2p_2 = \frac{2}{3}\text{.}\)
    • \(p_1 = 1\)
    • Yes. This is the factor \(1 - p_1\text{,}\) and it is the pure state where everyone uses Microsoft.
    🔗

    (f) The phase line.

    Which is the phase line for \(\dot{p}_1 = p_1(1 - p_1)(3p_1 - 2)\) on \([0, 1]\text{?}\)
    🔗
    • \(\underset{0}{\bullet} \longleftarrow\!\!\longleftarrow \underset{2/3}{\bullet} \longrightarrow\!\!\longrightarrow \underset{1}{\bullet}\)
    • Right. For \(0 \lt p_1 \lt \frac{2}{3}\text{,}\) the factors \(p_1\) and \(1 - p_1\) are positive and \(3p_1 - 2\) is negative, so \(\dot{p}_1 \lt 0\) and the arrows point left. For \(\frac{2}{3} \lt p_1 \lt 1\text{,}\) all three factors are positive, so the arrows point right.
    • \(\underset{0}{\bullet} \longrightarrow\!\!\longrightarrow \underset{2/3}{\bullet} \longleftarrow\!\!\longleftarrow \underset{1}{\bullet}\)
    • Not quite. The arrows are backward. For \(0 \lt p_1 \lt \frac{2}{3}\text{,}\) the factor \(3p_1 - 2\) is negative, so \(\dot{p}_1 \lt 0\) and the arrows point left.
    • \(\underset{0}{\bullet} \longrightarrow\!\!\longrightarrow \underset{2/3}{\bullet} \longrightarrow\!\!\longrightarrow \underset{1}{\bullet}\)
    • Not quite. The sign of \(\dot{p}_1\) changes at \(\frac{2}{3}\text{,}\) because the factor \(3p_1 - 2\) changes sign there: it is negative below \(\frac{2}{3}\text{.}\)
    • \(\underset{0}{\bullet} \longleftarrow\!\!\longleftarrow \underset{2/3}{\bullet} \longleftarrow\!\!\longleftarrow \underset{1}{\bullet}\)
    • Not quite. The sign of \(\dot{p}_1\) changes at \(\frac{2}{3}\text{,}\) because the factor \(3p_1 - 2\) changes sign there: it is positive above \(\frac{2}{3}\text{.}\)
    🔗
    From the phase line, we can read off the stability of each equilibrium:
    • \(p_1 = 0\) (everyone uses Apple) is stable.
      🔗
      🔗
    • \(p_1 = 1\) (everyone uses Microsoft) is stable.
      🔗
      🔗
    • \(p_1 = \frac{2}{3}\) is unstable. It is a tipping point between the other two.
      🔗
      🔗
    🔗
    You will be asked to interpret the equilibria and their stability in the checkpoints after the reading!
    🔗
    Compare this with the game analysis at the start of the example. The three equilibria of the replicator system match the three symmetric Nash equilibria exactly: \(p_1 = 1\) is \((m, m)\text{,}\) \(p_1 = 0\) is \((a, a)\text{,}\) and \(p_1 = \frac{2}{3}\) is \((\sigma^*, \sigma^*)\text{.}\) Even better, the stable equilibria are exactly the evolutionarily stable states \(m\) and \(a\text{,}\) and the unstable one is \(\sigma^*\text{,}\) which is not evolutionarily stable. We will see later that this is not a coincidence!

    Now let’s make sure you can correctly interpret the equilibria and their stability!
    🔗

    Checkpoint 10.1.5.

    For which initial Microsoft shares \(p_1(0)\) does the population eventually end up with everyone using Microsoft?
    🔗
    • \(p_1(0) \gt \frac{1}{2}\)
    • Not quite. A Microsoft majority is not enough. For every \(p_1\) between \(0\) and \(\frac{2}{3}\text{,}\) the Microsoft share shrinks.
    • \(p_1(0) \geq \frac{2}{3}\)
    • Close, but check the endpoint. If \(p_1(0) = \frac{2}{3}\text{,}\) the population starts at an equilibrium, so it stays at \(\frac{2}{3}\) forever.
    • \(p_1(0) \gt \frac{2}{3}\)
    • Right. This is the basin of attraction of \(p_1 = 1\text{.}\) Any population that starts with more than \(\frac{2}{3}\) using Microsoft ends up all Microsoft, even though everyone would be better off with Apple. Similarly, \([0, \frac{2}{3})\) is the basin of attraction of \(p_1 = 0\text{:}\) starting with fewer than \(\frac{2}{3}\) using Microsoft, everyone ends up with Apple.
    • \(p_1(0) \gt \frac{1}{3}\)
    • Not quite. The tipping point is at \(p_1 = \frac{2}{3}\text{,}\) not \(\frac{1}{3}\text{.}\) (It is \(p_2\) that equals \(\frac{1}{3}\) there.)
    🔗

    Checkpoint 10.1.6.

    Suppose the population starts at \(\sigma(0) = \frac{2}{3}m + \frac{1}{3}a\text{,}\) so \(p_1(0) = \frac{2}{3}\text{.}\) How does the population evolve over time?
    🔗
    • It stays at \(p_1 = \frac{2}{3}\) forever.
    • Right. \(p_1 = \frac{2}{3}\) is an equilibrium, so \(\dot{p}_1 = 0\) there and the population never moves. It is unstable, but that only matters if the population starts near \(\frac{2}{3}\) rather than exactly at it.
    • It moves toward everyone using Microsoft.
    • Not quite. That happens if the population starts above \(\frac{2}{3}\text{.}\) Starting exactly at the equilibrium, \(\dot{p}_1 = 0\text{,}\) so nothing changes.
    • It moves toward everyone using Apple.
    • Not quite. That happens if the population starts below \(\frac{2}{3}\text{.}\) Starting exactly at the equilibrium, \(\dot{p}_1 = 0\text{,}\) so nothing changes.
    🔗

    Remark 10.1.7.

    The book calls the mixed Nash equilibrium \(\sigma^* = \frac{2}{3}m + \frac{1}{3}a\) a “mystery”: why would anyone choose the worse computer with higher probability? Because \(\sigma^*\) is unstable, it is not a state the population is likely to settle into. It is better thought of as the tipping point between the two basins of attraction. Since Apple users get twice the payoff when they match, Microsoft needs more than \(\frac{2}{3}\) of the population before it does better than Apple. Any small deviation from \(\sigma^*\) sends the population all the way to everyone using Microsoft or everyone using Apple.
