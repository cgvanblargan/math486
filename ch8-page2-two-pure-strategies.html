    Section 8.4, Evolutionary Stability with Two Pure Strategies (Part 1).

    Read Section 8.4 up to (but not including) 8.4.1, Stag Hunt.
    🔗
    Theorem 8.5 splits the game into four cases:
    1. \(a \gt c\) and \(d \lt b\text{:}\) \(s_1\) strictly dominates \(s_2\text{.}\) The population state \(s_1\) is evolutionarily stable.
      🔗
      🔗
    2. \(a \lt c\) and \(d \gt b\text{:}\) \(s_2\) strictly dominates \(s_1\text{.}\) The population state \(s_2\) is evolutionarily stable.
      🔗
      🔗
    3. \(a \gt c\) and \(d \gt b\text{:}\) each strategy is the best response to itself. The population states \(s_1\) and \(s_2\) are evolutionarily stable, but the mixed state \(\sigma\) is not.
      🔗
      🔗
    4. \(a \lt c\) and \(d \lt b\text{:}\) each strategy is the best response to the other. The mixed state \(\sigma\) is evolutionarily stable.
      🔗
      🔗
    In cases (3) and (4), \(\sigma = ps_1 + (1 - p)s_2\text{,}\) with \(p\) given by formula (8.5).
    🔗
    Make sure you understand the statement of the theorem. Look through the proof for a bit to see the idea, but you can skip over the algebra.
    🔗
    🔗
    Let’s check our understanding with some questions. First, practice figuring out which case a game is in.
    🔗

    Checkpoint 8.2.3.

    Here is Chicken from Chapter 7, with \(s_1 = \) straight and \(s_2 = \) swerve. Which case of Theorem 8.5 is it?
    🔗
    • Case (3)
    • Not quite. Matching with the general matrix, \(a = -2\text{,}\) \(b = 1\text{,}\) \(c = -1\text{,}\) and \(d = 0\text{.}\) Case (3) needs \(a \gt c\text{,}\) but \(-2 \lt -1\text{.}\)
    • Case (4)
    • Right. Here \(a = -2\text{,}\) \(b = 1\text{,}\) \(c = -1\text{,}\) and \(d = 0\text{,}\) so \(a \lt c\) and \(d \lt b\text{.}\) By Theorem 8.5, there are three Nash equilibria: (straight, swerve), (swerve, straight), and \((\sigma, \sigma)\text{.}\) Only \((\sigma, \sigma)\) is symmetric, and \(\sigma\) is evolutionarily stable. By (8.5),
      \begin{equation*} p = \frac{d - b}{(a - c) + (d - b)} = \frac{0 - 1}{(-1) + (-1)} = \frac{1}{2}, \end{equation*}
      so \(\sigma\) goes straight half the time, just like we saw in Chapter 7.
    🔗

    Checkpoint 8.2.4.

    In case (4), why can we immediately rule out the Nash equilibria \((s_1, s_2)\) and \((s_2, s_1)\) when looking for evolutionarily stable states?
    🔗
    • They aren’t symmetric. An evolutionarily stable state is a population state \(\sigma\text{,}\) which goes with a symmetric profile \((\sigma, \sigma)\text{.}\)
    • Right. Everyone in the population plays against everyone else, so there is no “Player 1 strategy” and “Player 2 strategy.” Only symmetric Nash equilibria \((\sigma, \sigma)\) can give an evolutionarily stable state \(\sigma\text{.}\)
    • They aren’t strict Nash equilibria.
    • Not quite. They actually are strict: in case (4), switching strategies lowers your payoff. The problem is that they aren’t symmetric.
    🔗
    Okay, now back to the statement of the theorem! Some ideas follow pretty quickly from the previous section without any computation.
    🔗

    Checkpoint 8.2.5.

    In cases (1), (2), and (3), there are strict symmetric Nash equilibria of the form \((s_1, s_1)\) and/or \((s_2, s_2)\text{.}\) How do we immediately know the population states \(s_1\) and/or \(s_2\) are evolutionarily stable?
    🔗
    • We check condition (2) of Theorem 8.1 for every \(\tau \neq s_1\text{.}\)
    • Not quite. That would work, but it isn’t immediate. There’s a theorem that does all of that work for strict Nash equilibria.
    • By Theorem 8.2, since they come from strict symmetric Nash equilibria.
    • Right. Theorem 8.2 says that if \((\sigma, \sigma)\) is a strict Nash equilibrium, then \(\sigma\) is evolutionarily stable. No further checking needed!
    🔗
    In cases (1) and (2), the only Nash equilibria use pure strategies. Recall that being a Nash equilibrium is required (but not sufficient) for evolutionary stability. In case (3), there is a mixed symmetric Nash equilibrium \((\sigma, \sigma)\text{,}\) but \(\sigma\) is not evolutionarily stable. The book shows this with a computation, but we can actually see why without any computation.
    🔗

    Checkpoint 8.2.6.

    In case (3), why is the mixed state \(\sigma\) not evolutionarily stable?
    🔗
    • Because \((\sigma, \sigma)\) is not a strict Nash equilibrium.
    • Not quite. It’s true that \((\sigma, \sigma)\) is not strict, but that doesn’t rule out evolutionary stability. In case (4), \((\sigma, \sigma)\) isn’t strict either, and \(\sigma\) is evolutionarily stable there!
    • Because of Theorem 8.3: \(\sigma\) uses both pure strategies, and \((s_1, s_1)\) (or \((s_2, s_2)\)) is also a Nash equilibrium.
    • Right. Since \(0 \lt p \lt 1\text{,}\) all pure strategies are active in \(\sigma\text{.}\) If \(\sigma\) were evolutionarily stable, Theorem 8.3 would say \((\tau, \tau)\) is not a Nash equilibrium for any \(\tau \neq \sigma\text{.}\) But \(\tau = s_1\) gives the Nash equilibrium \((s_1, s_1)\text{,}\) so \(\sigma\) can’t be evolutionarily stable. (Using \(\tau = s_2\) works just as well, since \((s_2, s_2)\) is a Nash equilibrium too.)
    🔗
    Theorem 8.5 doesn’t cover every game. Here is a variation of Stag Hunt (Section 8.4.2 in the book), where a hunter who hunts the stag alone has a \(\frac{1}{4}\) chance of catching it. The pure strategy Nash equilibria are boxed.
    🔗
    Here \(b = d = 1\text{,}\) so Theorem 8.5 doesn’t apply. Notice the following Nash equilibria:
    • (stag, stag) is a strict Nash equilibrium: switching to hare drops your payoff from 2 to 1.
      🔗
      🔗
    • (hare, hare) is a Nash equilibrium, but it is not strict: switching to stag still gives you 1.
      🔗
      🔗
    🔗
    By the same reasoning as in the questions above:
    • Because (stag, stag) is a strict symmetric Nash equilibrium, Theorem 8.2 says the population state stag is evolutionarily stable.
      🔗
      🔗
    • A mixed state uses both pure strategies, so if it were evolutionarily stable, Theorem 8.3 would say (stag, stag) can’t be a Nash equilibrium. Since (stag, stag) is a Nash equilibrium, there are no mixed evolutionarily stable states. (The same argument works using (hare, hare), which is also a Nash equilibrium.)
      🔗
      🔗
    🔗
    So the only state that isn’t settled right away is hare. Since (hare, hare) isn’t strict, we have to check the two conditions of Theorem 8.1 directly.
    🔗
