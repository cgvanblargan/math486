    Section 5.2 Tennis, and Other Ways to Find Mixed Equilibria

    On the last page we verified that \((.6b + .4f,\ .7b + .3f)\) is a mixed strategy Nash equilibrium. But we want to find all of them. We already checked there are no pure ones, so let’s look for equilibria where both players use both strategies.
    🔗
    Here’s the Fundamental Theorem of Nash Equilibria (Theorem 5.2) again. A mixed strategy profile \(\sigma\) is a Nash equilibrium exactly when, for every player \(i\text{:}\)
    1. If \(s_i\) and \(s_i'\) are both active, then \(\pi_i(s_i, \sigma_{-i}) = \pi_i(s_i', \sigma_{-i})\text{.}\)
      🔗
      That is, every active strategy earns player \(i\) the same payoff when the other players’ strategies are fixed as in \(\sigma\text{.}\)
      🔗
      🔗
    2. If \(s_i\) is active and \(s_i'\) is not, then \(\pi_i(s_i, \sigma_{-i}) \geq \pi_i(s_i', \sigma_{-i})\text{.}\)
      🔗
      That is, player \(i\) is never better off switching to an inactive strategy.
      🔗
      🔗
    🔗
    Since in this example we are looking for all Nash equilibria where both players use both strategies, only condition (1) matters. Let’s start with the receiver.
    🔗

    Checkpoint 5.2.2.

    Suppose both of the receiver’s strategies are active. In words, what does condition (1) of Theorem 5.2 say about her?
    🔗
    • She anticipates each side half the time.
    • Equal payoffs doesn’t mean equal probabilities. Condition (1) is about what her strategies earn, not how often she uses them.
    • Against the server’s mix, anticipating the backhand and anticipating the forehand earn her the same expected payoff.
    • Correct. If one earned more, she’d drop the other one. She’s only willing to mix if she’s indifferent.
    • Her two strategies earn the server the same expected payoff.
    • Wrong player. Condition (1) is about each player’s own payoffs. The receiver cares about what her strategies earn her.
    🔗
    More formally, this means \(\pi_2(\sigma_1, b) = \pi_2(\sigma_1, f)\text{,}\) where \(\sigma_1 = pb + (1-p)f\) (notice \(p\) is unspecified because we are solving for the \(p\) that makes this mixed strategy part of a Nash equilibrium!). Let’s compute each side separately, reading down the receiver’s columns in Table 5.2.1 using the second numbers, weighted by the server’s probabilities. If she anticipates \(b\text{:}\)
    \begin{equation*} \pi_2(pb + (1-p)f,\ b) = \underbrace{p}_{\substack{\text{prob. server}\\ \text{goes } b}} \cdot \underbrace{(.6)}_{\substack{\text{payoff}\\ \text{at } (b, b)}} + \underbrace{(1-p)}_{\substack{\text{prob. server}\\ \text{goes } f}} \cdot \underbrace{(.3)}_{\substack{\text{payoff}\\ \text{at } (f, b)}} \end{equation*}
    If she anticipates \(f\text{,}\) it’s the same pattern using the other column:
    \begin{equation*} \pi_2(pb + (1-p)f,\ f) = p(.2) + (1-p)(.9) \end{equation*}
    Setting these equal and solving for \(p\text{:}\)
    \begin{align*} p(.6) + (1-p)(.3) \amp = p(.2) + (1-p)(.9)\\ .3 + .3p \amp = .9 - .7p\\ p \amp = .6 \end{align*}
    Notice that we found the server’s \(p\) using the receiver’s payoffs. That’s what we saw on the last page: the server’s mix is what keeps the receiver indifferent.
    🔗
    Now it’s your turn with the server.
    🔗

    Checkpoint 5.2.3.

    Both of the server’s strategies are active. What equation does condition (1) of Theorem 5.2 give us?
    🔗
    • \(\pi_2(\sigma_1, b) = \pi_2(\sigma_1, f)\)
    • That’s the receiver’s condition, the one we just used to find \(p\text{.}\) Now we want the server to be indifferent, so we need the server’s payoffs.
    • \(\pi_1(\sigma_1, b) = \pi_1(\sigma_1, f)\)
    • Right payoffs, wrong slot. This compares the receiver’s two strategies. The server is indifferent between her own strategies, which go in the first slot.
    • \(\pi_1(b, \sigma_2) = \pi_1(f, \sigma_2)\)
    • Correct. The server’s own payoffs, comparing her two strategies, against the receiver’s mix \(\sigma_2 = qb + (1-q)f\text{.}\)
    🔗

    Checkpoint 5.2.4.

    Which equation do you get when you compute both sides of \(\pi_1(b, \sigma_2) = \pi_1(f, \sigma_2)\text{?}\) (On the last page you computed \(\pi_1(b, \sigma_2)\) with \(q = .7\text{.}\) Do the same thing, but leave \(q\) as a letter.)
    🔗
    • \(.4q + .8(1-q) = .7q + .1(1-q)\)
    • Correct. Each side reads across one of the server’s rows, using the first numbers, weighted by the receiver’s probabilities.
    • \(.6q + .2(1-q) = .3q + .9(1-q)\)
    • These are the receiver’s payoffs (the second numbers). The server cares about her own payoffs, the first numbers.
    • \(.4q + .7(1-q) = .8q + .1(1-q)\)
    • This reads down the columns, like we did for the receiver. But each side here is one of the server’s strategies, which is a row. Read across the row, weighting its two cells by \(q\) and \(1-q\text{.}\)
    🔗

    Example 5.2.5. Solving for \(q\).

    Solve \(.4q + .8(1-q) = .7q + .1(1-q)\) for \(q\text{.}\)
    🔗
    Solution.
    \begin{align*} .8 - .4q \amp = .1 + .6q\\ q \amp = .7 \end{align*}
    Same as the last page!
    🔗
    🔗
    🔗
    So \((.6b + .4f,\ .7b + .3f)\) is the only mixed strategy Nash equilibrium where both players use both strategies.
    🔗

    Section 5.3 finds the same equilibrium two other ways. The first uses calculus. Since the values of \(p\) and \(q\) determine the mixed strategy profile, we can think of the payoffs as functions \(\pi_1(p, q)\) and \(\pi_2(p, q)\text{.}\)
    🔗
    Before reading, let’s figure out what the derivatives should do at a Nash equilibrium where both players mix. Recall Theorem 5.3: at a Nash equilibrium, any mix of a player’s active strategies earns her the same payoff. We saw this on the last page. For example, when the receiver plays \(q = .7\) (her Nash equilibrium strategy), the server gets a payoff of \(.52\) for every \(p\text{.}\) How does this relate to the derivative with respect to \(p\text{?}\)
    🔗

    Checkpoint 5.2.6.

    Suppose \((p, q)\) is a Nash equilibrium with \(0 \lt p \lt 1\) and \(0 \lt q \lt 1\text{.}\) Which is true?
    🔗
    • \(\dfrac{\partial \pi_1}{\partial q} = 0\) and \(\dfrac{\partial \pi_2}{\partial p} = 0\text{.}\)
    • Tempting, since each player’s mix keeps the other player indifferent. But the indifference is in each player’s own choice: the server doesn’t care what \(p\) she picks. That’s a statement about \(\pi_1\) as \(p\) changes.
    • \(\dfrac{\partial \pi_1}{\partial p} = 0\) and \(\dfrac{\partial \pi_1}{\partial q} = 0\text{.}\)
    • The server only controls \(p\text{.}\) If the receiver changes \(q\text{,}\) the server’s payoff can certainly change. What Theorem 5.3 tells us is that the server’s own choice of \(p\) doesn’t matter.
    • \(\dfrac{\partial \pi_1}{\partial p} = 0\) and \(\dfrac{\partial \pi_2}{\partial q} = 0\text{.}\)
    • Correct. Each player’s payoff is flat in her own variable, so its derivative is \(0\text{.}\) Heads up: unlike Chapter 1, a zero derivative doesn’t mean a peak here. \(\pi_1\) is a line in \(p\text{,}\) so a zero derivative means the line is flat.
    🔗

    Checkpoint 5.2.7.

    The book explains the server’s best response. Now think about the receiver. Suppose the server uses some \(p \lt .6\text{.}\) What is the receiver’s best response, and why?
    🔗
    • Any \(q\text{,}\) since she’s indifferent.
    • She’s only indifferent at exactly \(p = .6\text{.}\) For any other \(p\text{,}\) one of her pure strategies is strictly better.
    • \(q = 0\text{.}\) Since \(\dfrac{\partial \pi_2}{\partial q} \lt 0\text{,}\) her payoff goes down as \(q\) goes up, so she should use the smallest possible value for \(q\) (which is \(0\)).
    • Correct. Similarly, if \(p \gt .6\) her best response is \(q = 1\text{,}\) and if \(p = .6\) any \(q\) works.
    • It depends. If \(p \gt .5\) the server mostly serves to the backhand, so \(q = 1\text{.}\) If \(p \lt .5\text{,}\) then \(q = 0\text{.}\)
    • The cutoff is \(.6\text{,}\) not \(.5\text{.}\) She returns an anticipated forehand much more often than an anticipated backhand (\(.9\) versus \(.6\)), so she keeps anticipating the forehand until backhand serves get frequent enough.
    🔗

    Checkpoint 5.2.8.

    How do the graphs of \(B_1\) and \(B_2\) in Figure 5.1 relate to the Nash equilibria?
    🔗
    • The Nash equilibria are the points where the two graphs intersect.
    • Correct. At an intersection, each player’s strategy is a best response to the other’s. That’s the definition of a Nash equilibrium!
    • Every point on the vertical segment of \(B_1\) is a Nash equilibrium, since the server is indifferent there.
    • The server is best responding, but the receiver might not be. At \((p, q) = (1, .7)\text{,}\) for example, the receiver’s best response to \(p = 1\) is \(q = 1\text{,}\) not \(.7\text{.}\)
    • Any point on either graph is a Nash equilibrium.
    • A point on \(B_1\) only means the server is best responding. For a Nash equilibrium, both players have to be best responding at the same time.
