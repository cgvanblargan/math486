    Exercises 10.5 Answers to Ch. 10 Exercises

    Answers to the exercises of this chapter. Click an exercise to open it, click a part to open that part, then click Solution to reveal the answer.
    🔗
    These are the answers to the questions, not fully worked solutions. Enough is shown that you can tell whether your own work got to the correct conclusion.
    🔗

    1. Deriving the Replicator Equation.

    (a) The replicator system.

    Derive the replicator system.
    🔗
    Solution.
    \(\dot{p}_1 = (4p_2 - 5p_1p_2)p_1\) and \(\dot{p}_2 = (p_1 - 5p_1p_2)p_2\)
    🔗
    🔗
    🔗

    (b) One equation.

    Reduce to \(\dot{p} = f(p)\text{.}\)
    🔗
    Solution.
    \(\dot{p} = p(1 - p)(4 - 5p)\)
    🔗
    🔗
    🔗

    (c) Equilibria.

    Find the equilibria.
    🔗
    Solution.
    \(p = 0\text{,}\) \(p = \frac{4}{5}\text{,}\) and \(p = 1\)
    🔗
    🔗
    🔗

    (d) Using Theorems 10.1 and 10.2.

    Explain why \(p = 0\) and \(p = 1\) are equilibria, and which theorem says the interior equilibrium has equal payoffs.
    🔗
    Solution.
    Theorem 10.1(4): \(p = 0\) and \(p = 1\) are pure states. Theorem 10.2: at an interior equilibrium \(\sigma^*\text{,}\) both strategies are active, so \(\pi_1(a, \sigma^*) = \pi_1(b, \sigma^*)\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2. Phase Line and Stability.

    (a) The phase line.

    Sketch \(f(p)\) and the phase line.
    🔗
    Solution.
    \(\underset{0}{\bullet} \longrightarrow\!\!\longrightarrow \underset{4/5}{\bullet} \longleftarrow\!\!\longleftarrow \underset{1}{\bullet}\)
    🔗
    🔗
    🔗

    (b) Typical solutions.

    Describe a typical solution.
    🔗
    Solution.
    Every solution starting in \((0, 1)\) approaches \(p = \frac{4}{5}\text{.}\) Near 0, \(p\) increases; near 1, \(p\) decreases.
    🔗
    🔗
    🔗

    (c) Connection to Theorem 8.5.

    Which case of Theorem 8.5, and how does it connect to part (b)?
    🔗
    Solution.
    Case (4) (\(a \lt c\text{,}\) \(d \lt b\)): the only evolutionarily stable state is \(\frac{4}{5}a + \frac{1}{5}b\text{,}\) the same as the stable equilibrium.
    🔗
    🔗
    🔗

    (d) Starting at the equilibrium.

    Start exactly at the interior equilibrium, then just below it.
    🔗
    Solution.
    It stays at \(\frac{4}{5}\) forever. Just below, \(p\) increases toward \(\frac{4}{5}\text{.}\)
    🔗
    🔗
    🔗
    🔗

    3. A Game Outside the Four Cases.

    (a) One equation.

    Reduce to \(\dot{p} = f(p)\text{.}\)
    🔗
    Solution.
    \(\dot{p} = -p(1 - p)^2\)
    🔗
    🔗
    🔗

    (b) Equilibria.

    Find the equilibria.
    🔗
    Solution.
    \(p = 0\) and \(p = 1\)
    🔗
    🔗
    🔗

    (c) The phase line.

    Sketch \(f(p)\) and the phase line.
    🔗
    Solution.
    \(\underset{0}{\bullet} \longleftarrow\!\!\longleftarrow\!\!\longleftarrow\!\!\longleftarrow \underset{1}{\bullet}\text{:}\) \(p = 0\) is stable and \(p = 1\) is unstable.
    🔗
    🔗
    🔗

    (d) Interpretation.

    Interpret part (c).
    🔗
    Solution.
    Unless everyone starts with \(s\text{,}\) \(s\) dies out and the population approaches all-\(h\text{.}\)
    🔗
    🔗
    🔗

    (e) No other symmetric Nash equilibria.

    Which theorem shows there are no other symmetric Nash equilibria?
    🔗
    Solution.
    Theorem 10.2: a symmetric Nash equilibrium \((\sigma, \sigma)\) satisfies condition (1), so \(\sigma\) is an equilibrium of the replicator system. By part (b), the only equilibria are \(p = 0\) and \(p = 1\text{.}\)
    🔗
    🔗
    🔗

    (f) Comparing with evolutionary stability.

    Compare with the evolutionarily stable states, and explain why the game is not in Figure 10.3.
    🔗
    Solution.
    The only evolutionarily stable state is \(h\text{,}\) which matches the stable equilibrium \(p = 0\text{.}\) The game has \(a = c = 4\text{,}\) and the four cases require \(a \neq c\text{.}\)
    🔗
    🔗
    🔗

    (g) Theorem 10.3 at all-\(s\).

    Compute the payoffs at all-\(s\text{,}\) decide whether Theorem 10.3 applies, and explain why there is no contradiction.
    🔗
    Solution.
    \(\pi_1(h, \sigma) = 4 = \pi_1(\sigma, \sigma)\text{,}\) so the strict inequality fails and Theorem 10.3 does not apply. No contradiction: Theorem 10.3 only gives one way an equilibrium can fail to be approached. It doesn’t say every unstable equilibrium is of that kind.
    🔗
    🔗
    🔗
    🔗

    4. Using the Theorems with Three Strategies.

    (a) Three equilibria.

    Name three equilibria using Theorem 10.1.
    🔗
    Solution.
    All-\(F\text{,}\) all-\(S\text{,}\) and all-\(P\text{.}\)
    🔗
    🔗
    🔗

    (b) The all-\(F\) state.

    Use best response to show \((F, F)\) is not a Nash equilibrium, and explain why this doesn’t contradict Theorem 10.2.
    🔗
    Solution.
    Player 2: \(F\) Player 2: \(S\) Player 2: \(P\)
    Player 1: \(F\) \((6, 6)\) \((-2, \boxed{10})\) \((\boxed{6}, 6)\)
    Player 1: \(S\) \((\boxed{10}, -2)\) \((\boxed{0}, \boxed{0})\) \((5, -1)\)
    Player 1: \(P\) \((6, \boxed{6})\) \((-1, 5)\) \((\boxed{6}, \boxed{6})\)
    \((F, F)\) has no boxes, so it is not a Nash equilibrium. No contradiction: Theorem 10.2 only requires condition (1), which holds since \(F\) is the only active strategy.
    🔗
    🔗
    🔗

    (c) Invading all-\(F\).

    Apply Theorem 10.3 at all-\(F\text{,}\) and consider starting with no \(S\)-players.
    🔗
    Solution.
    Since \(10 \gt 6\text{,}\) no solution containing some \(S\)-players approaches all-\(F\text{.}\) With no \(S\)-players, the population stays at all-\(F\) (Theorem 10.1(4)).
    🔗
    🔗
    🔗

    (d) The all-\(S\) state.

    Use a theorem from Chapter 8 and one from Chapter 10 to show all-\(S\) is asymptotically stable.
    🔗
    Solution.
    Theorem 8.2: \((S, S)\) is a strict Nash equilibrium, so all-\(S\) is evolutionarily stable. Theorem 10.4: so it is an asymptotically stable equilibrium.
    🔗
    🔗
    🔗

    (e) The classmate’s error.

    Explain the error in the classmate’s reasoning.
    🔗
    Solution.
    Theorem 10.4 only goes from evolutionarily stable to asymptotically stable. It says nothing about a state that is not evolutionarily stable.
    🔗
    🔗
