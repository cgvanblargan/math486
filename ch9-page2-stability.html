    Section 9.2 Stability and the Phase Line

    On the previous page, we found the equilibria of an autonomous differential equation \(\frac{dp}{dt} = f(p)\text{.}\) As we mentioned, we can study the behavior of solutions without actually finding the general solution. On this page, we look at solutions that start near an equilibrium and determine whether they move toward it or away from it. This ultimately lets us understand the long-term behavior of solutions.
    🔗

    An unstable equilibrium.

    Recall that \(\frac{dp}{dt} = p\) has general solution \(p(t) = Ce^t\text{,}\) and its only equilibrium is \(p = 0\text{.}\) Here are several solutions again, with the equilibrium highlighted:
    🔗
    🔗
    A solution that starts slightly above 0 grows, and a solution that starts slightly below 0 decreases. Either way, it moves away from the equilibrium, no matter how close to 0 it starts. We call the equilibrium \(p = 0\) unstable.
    🔗

    A stable equilibrium.

    Now consider \(\frac{dp}{dt} = -p\text{.}\) A quick check shows that \(p(t) = Ce^{-t}\) is the general solution, since \(\frac{d}{dt}\left(Ce^{-t}\right) = -Ce^{-t}\text{.}\) Again, the only equilibrium is \(p = 0\text{.}\)
    🔗
    🔗
    This time, every solution approaches 0 as \(t \to \infty\text{,}\) from above or from below. We call the equilibrium \(p = 0\) stable.
    🔗

    The phase line.

    We will skip over some of the underlying theory, but the ideas for doing this with any \(\frac{dp}{dt} = f(p)\) are simple, as long as \(f\) is nice enough (for example, if \(f\) has a continuous derivative, which is true for every \(f\) in this class). In that case, solutions can’t cross each other. In particular, a solution can never cross an equilibrium, so a solution that starts between two equilibria stays between them.
    🔗
    This means we only need to know the sign of \(f(p)\text{:}\)
    • Where \(f(p) \gt 0\text{,}\) we have \(\frac{dp}{dt} \gt 0\text{,}\) so \(p\) is increasing.
      🔗
      🔗
    • Where \(f(p) \lt 0\text{,}\) we have \(\frac{dp}{dt} \lt 0\text{,}\) so \(p\) is decreasing.
      🔗
      🔗
    🔗
    For example, take \(\frac{dp}{dt} = (p - 2)(p + 3)\) from the previous page, with equilibria \(p = -3\) and \(p = 2\text{.}\) Checking the sign of each factor:
    • For \(p \lt -3\text{,}\) both factors are negative, so \(\frac{dp}{dt} \gt 0\) and \(p\) is increasing.
      🔗
      🔗
    • For \(-3 \lt p \lt 2\text{,}\) \(p - 2 \lt 0\) and \(p + 3 \gt 0\text{,}\) so \(\frac{dp}{dt} \lt 0\) and \(p\) is decreasing.
      🔗
      🔗
    • For \(p \gt 2\text{,}\) both factors are positive, so \(\frac{dp}{dt} \gt 0\) and \(p\) is increasing.
      🔗
      🔗
    🔗
    We record this on a phase line: a number line for \(p\text{,}\) with a dot at each equilibrium and an arrow on each interval between them. An arrow pointing right means \(p\) is increasing there, and an arrow pointing left means \(p\) is decreasing.
    🔗
    🔗
    Understanding how the three pictures relate lets you visualize how the sign of \(f(p)\) determines what happens to the solutions. However, we can determine stability directly from the phase line:
    • At \(p = -3\text{,}\) the arrows on both sides point toward the equilibrium. Solutions that start near \(-3\) approach it, so \(p = -3\) is stable.
      🔗
      🔗
    • At \(p = 2\text{,}\) the arrows on both sides point away from the equilibrium. Solutions that start near 2 move away from it, so \(p = 2\) is unstable.
      🔗
      🔗
    🔗
    You should be able to connect these ideas to the direction of the arrows and to the sketches of solutions approaching or moving away from the equilibria. However, the precise reason this always works depends on an existence and uniqueness theorem, which we won’t go into.
    🔗

    A semistable equilibrium.

    There is one more possibility: the arrows on both sides can point the same way. For example, \(\frac{dp}{dt} = (p + 1)^2\) has the equilibrium \(p = -1\text{,}\) and \((p + 1)^2 \gt 0\) on both sides of it.
    🔗
    🔗
    Solutions that start below \(-1\) approach it, but solutions that start above \(-1\) move away from it. We call \(p = -1\) semistable. Since some nearby solutions move away, a semistable equilibrium is not stable.
    🔗

    The technical definitions.

    For all the equations in this class, stability will work out the way we have described, by reading the phase line. For reference, here are the technical definitions from Section 9.4.3 of the book, written for one variable.
    🔗
    🔗

    Definition 9.2.5 Stable and Asymptotically Stable.

    Let \(k\) be an equilibrium of \(\frac{dp}{dt} = f(p)\text{.}\)
    • \(k\) is stable if solutions that start near \(k\) stay near \(k\) in future time. More precisely, for each \(\epsilon \gt 0\) there is a \(\delta \gt 0\) such that if \(|p(0) - k| \lt \delta\text{,}\) then \(|p(t) - k| \lt \epsilon\) for all \(t \geq 0\text{.}\)
      🔗
      🔗
    • \(k\) is asymptotically stable if solutions that start near \(k\) stay near \(k\) in future time, and in addition approach \(k\) as \(t \to \infty\text{.}\) More precisely, for each \(\epsilon \gt 0\) there is a \(\delta \gt 0\) such that if \(|p(0) - k| \lt \delta\text{,}\) then (i) \(|p(t) - k| \lt \epsilon\) for all \(t \geq 0\text{,}\) and (ii) \(p(t) \to k\) as \(t \to \infty\text{.}\)
      🔗
      🔗
    An equilibrium that is not stable is called unstable.
    🔗
    🔗
    On a phase line, if the arrows on both sides point toward an equilibrium, it is asymptotically stable. If the arrows on at least one side point away, it is unstable. So in this class, when we call an equilibrium on a phase line “stable,” we mean asymptotically stable.
    🔗

    Definition 9.2.6 Basin of Attraction.

    The basin of attraction of an asymptotically stable equilibrium \(k\) is the set of starting values \(p(0)\) whose solutions approach \(k\) as \(t \to \infty\text{.}\)
    🔗
    🔗
    For example, for \(\frac{dp}{dt} = (p - 2)(p + 3)\text{,}\) every solution that starts below 2 approaches \(-3\text{,}\) so the basin of attraction of \(p = -3\) is \((-\infty, 2)\text{.}\) Solutions that start at exactly \(p(0) = 2\) stay at 2, and solutions that start above 2 increase without bound.
    🔗
    Let’s practice with an equation that will look familiar in Chapter 10.
    🔗

    Checkpoint 9.2.7.

    Which is the phase line for \(\frac{dp}{dt} = p(1 - p)\text{?}\)
    🔗
    • \(\longleftarrow \underset{0}{\bullet} \longrightarrow\!\!\longrightarrow \underset{1}{\bullet} \longleftarrow\)
    • Right. For \(p \lt 0\text{,}\) \(p \lt 0\) and \(1 - p \gt 0\text{,}\) so \(\frac{dp}{dt} \lt 0\text{.}\) For \(0 \lt p \lt 1\text{,}\) both factors are positive, so \(\frac{dp}{dt} \gt 0\text{.}\) For \(p \gt 1\text{,}\) \(1 - p \lt 0\text{,}\) so \(\frac{dp}{dt} \lt 0\text{.}\) So \(p = 0\) is unstable and \(p = 1\) is stable.
    • \(\longrightarrow \underset{0}{\bullet} \longleftarrow\!\!\longleftarrow \underset{1}{\bullet} \longrightarrow\)
    • Not quite. The arrows are backward. Try a value between 0 and 1, like \(p = \frac{1}{2}\text{:}\) both factors are positive, so \(\frac{dp}{dt} \gt 0\text{.}\)
    • \(\longrightarrow \underset{0}{\bullet} \longrightarrow\!\!\longrightarrow \underset{1}{\bullet} \longrightarrow\)
    • Not quite. Check the sign for \(p \gt 1\text{:}\) then \(1 - p \lt 0\text{,}\) so \(\frac{dp}{dt} \lt 0\text{.}\)
    • \(\longleftarrow \underset{0}{\bullet} \longleftarrow\!\!\longleftarrow \underset{1}{\bullet} \longleftarrow\)
    • Not quite. Check the sign for \(0 \lt p \lt 1\text{:}\) both factors are positive, so \(\frac{dp}{dt} \gt 0\text{.}\)
    🔗

    Checkpoint 9.2.8.

    For \(\frac{dp}{dt} = p(1 - p)\text{,}\) what is the basin of attraction of the stable equilibrium \(p = 1\text{?}\)
    🔗
    • \([0, \infty)\)
    • Close, but check \(p(0) = 0\text{:}\) that solution stays at the equilibrium 0 forever, so it never approaches 1.
    • \((0, \infty)\)
    • Right. Every solution that starts above 0 approaches 1: from below if \(0 \lt p(0) \lt 1\text{,}\) and from above if \(p(0) \gt 1\text{.}\)
    • \((0, 1)\)
    • Not quite. Solutions that start above 1 also approach 1, since the arrow for \(p \gt 1\) points left.
    • \((-\infty, \infty)\)
    • Not quite. Solutions that start below 0 decrease, moving away from 0 and never reaching 1.
