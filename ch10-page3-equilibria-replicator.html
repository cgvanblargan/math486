    Section 10.3 Equilibria of the Replicator System

    We have already seen some connections between equilibria of the replicator system, Nash equilibria, and evolutionarily stable states. This makes sense, since in each of these settings, an equilibrium is often a state that a population tends toward or gets stuck at. In this section, we look at some theorems that make these connections clearer!
    🔗
    Before reading, let’s recall two things:
    🔗
    An equilibrium is asymptotically stable if every solution that starts close enough to it stays close to it and approaches it as \(t \to \infty\text{.}\) On a phase line, this means the arrows on both sides point toward it.
    🔗
    The theorems also refer to the two conditions of Theorem 5.2, the Fundamental Theorem of Nash Equilibria (see Section 5.1, Nash’s Theorem and the Fundamental Theorem). For a population state \(\sigma\text{,}\) \((\sigma, \sigma)\) is a Nash equilibrium exactly when:
    1. every active strategy at \(\sigma\) earns the same payoff \(\pi_1(s_i, \sigma)\text{,}\) and
      🔗
      🔗
    2. no inactive strategy earns more than the active strategies.
      🔗
      🔗
    🔗

    Section 10.6, Equilibria of the Replicator System.

    Read Section 10.6, as follows:
    • Read the statements and proofs of Theorems 10.2 and 10.3, and the paragraph after the proof of Theorem 10.3 that interprets it.
      🔗
      🔗
    • Read the statement of Theorem 10.4. You can skip Lemma 10.5 and the proof of Theorem 10.4.
      🔗
      🔗
    🔗
    🔗
    Let’s restate each theorem for reference and explore each one a bit further!
    🔗

    Theorem 10.3.1 Theorem 10.2.

    Let \(p \in \Sigma\text{,}\) and let \(\sigma\) be the corresponding population state. Then \(p\) is an equilibrium of the replicator system if and only if \((\sigma, \sigma)\) satisfies condition (1) of the Fundamental Theorem of Nash Equilibria (Theorem 5.2).
    🔗
    In other words, if \(p \in \Sigma_I\) for some nonempty subset \(I\) of \(\{1, \ldots, n\}\text{,}\) then \(p\) is an equilibrium of the replicator system if and only if all \(\pi_1(s_i, \sigma)\) with \(i \in I\) are equal.
    🔗
    🔗
    So a population state is an equilibrium exactly when every active strategy earns the same payoff. As in condition (1) of the Fundamental Theorem of Nash Equilibria, only the active strategies are compared.
    🔗
    We saw this in Microsoft vs. Apple: the equilibrium \(p_1 = \frac{2}{3}\) is exactly where Microsoft and Apple users earn the same payoff.
    🔗

    Checkpoint 10.3.2.

    Suppose every strategy is active at \(\sigma\) (all \(p_i \gt 0\)). Which statement is true?
    🔗
    • \(\sigma\) is an equilibrium if and only if \((\sigma, \sigma)\) is a Nash equilibrium.
    • Right. Condition (2) of Theorem 5.2 is about inactive strategies, and here there are none. So a Nash equilibrium only needs condition (1), which is exactly what Theorem 10.2 requires for an equilibrium.
    • \(\sigma\) can be an equilibrium without \((\sigma, \sigma)\) being a Nash equilibrium.
    • Not quite. That can only happen if condition (2) fails, which needs an inactive strategy that does better. Here every strategy is active.
    • \((\sigma, \sigma)\) can be a Nash equilibrium without \(\sigma\) being an equilibrium.
    • Not quite. A Nash equilibrium satisfies condition (1), so by Theorem 10.2 it is always an equilibrium.
    🔗

    Theorem 10.3.3 Theorem 10.3.

    Let \(p^* \in \Sigma_I\) be an equilibrium of the replicator system, and let \(\sigma^*\) be the corresponding population state. Suppose \((\sigma^*, \sigma^*)\) does not satisfy condition (2) of Theorem 5.2; that is, suppose there is an \(i \notin I\) such that \(\pi_1(s_i, \sigma^*) \gt \pi_1(\sigma^*, \sigma^*)\text{.}\) Let \(J\) be a subset of \(\{1, \ldots, n\}\) that includes both \(i\) and \(I\text{.}\) Then no solution \(p(t)\) of the replicator system that lies in \(\Sigma_J\) approaches \(p^*\) as \(t \to \infty\text{.}\)
    🔗
    🔗
    The idea is simpler than it looks! If an inactive strategy \(s_i\) would do better than the population average, the population can’t settle at that state. In this case, \(p^*\) is an equilibrium, but it is an unstable one! If you introduce a few individuals using the better strategy \(s_i\text{,}\) their share grows, so the population moves away. (If that strategy stays inactive, the population can stay at \(p^*\text{,}\) since by Theorem 10.1(1) an inactive strategy never appears on its own.)
    🔗
    Combined with Theorem 10.2, this says that a population can only settle at a Nash equilibrium. Theorem 10.2 handles condition (1), and Theorem 10.3 handles condition (2).
    🔗

    Checkpoint 10.3.4.

    In Hawks and Doves, consider the all-dove state \(p_1 = 0\text{.}\) Hawks are inactive, but a hawk would earn \(v\) against the doves, while the doves earn only \(\frac{v}{2} - t\text{.}\) What does Theorem 10.3 tell us?
    🔗
    • The all-dove state is an equilibrium, but no solution with some hawks approaches it.
    • Right. Since \(v \gt \frac{v}{2} - t\text{,}\) the inactive strategy \(h\) does better, so condition (2) fails. A few hawks invade, and the population moves away. That’s why \(p_1 = 0\) was unstable on the phase line on the previous page.
    • The all-dove state is not an equilibrium.
    • Not quite. The all-dove state is a pure state, so it is an equilibrium (Theorem 10.1(4)). Theorem 10.3 is about whether solutions approach it.
    • A population that starts with all doves will eventually have some hawks.
    • Not quite. An inactive strategy never appears on its own (Theorem 10.1(1)), so an all-dove population stays all doves. Theorem 10.3 is about populations that already have a few hawks.
    🔗
    And last, we have Theorem 10.4!
    🔗

    Theorem 10.3.5 Theorem 10.4.

    Let \(p^* \in \Sigma\text{.}\) Suppose the corresponding population state \(\sigma^*\) is evolutionarily stable. Then \(p^*\) is an asymptotically stable equilibrium of the replicator system.
    🔗
    🔗
    So every evolutionarily stable state is asymptotically stable. Being evolutionarily stable (Chapter 8) is a static condition: we look at a single, fixed state \(\sigma^*\) and check that any small group of invaders does worse than the rest of the population. Nothing changes over time. Being asymptotically stable is a dynamic condition: it is about how the population changes over time, returning to \(\sigma^*\) after small deviations. Theorem 10.4 says the static condition guarantees the dynamic one.
    🔗
    This theorem only goes in one direction. An asymptotically stable equilibrium does not have to be an evolutionarily stable state. For games with two pure strategies, though, the two ideas match exactly in the four cases of Figure 10.3 (when \(a \neq c\) and \(b \neq d\)), as we saw in Table 10.2.2 on the previous page.
    🔗

    Checkpoint 10.3.6.

    In Hawks and Doves, the mixed state \(\sigma^* = p_1^* h + (1 - p_1^*)d\) with \(p_1^* = \frac{v + 2t}{w + 2t}\) is evolutionarily stable (case (4) of Theorem 8.5). What does Theorem 10.4 tell us?
    🔗
    • \(p_1^*\) is an asymptotically stable equilibrium of the replicator system.
    • Right. This matches the phase line we found on the previous page, where the arrows on both sides point toward \(p_1^*\text{.}\)
    • \(p_1^*\) is the only equilibrium of the replicator system.
    • Not quite. \(p_1 = 0\) and \(p_1 = 1\) are also equilibria (Theorem 10.1(4)). Theorem 10.4 is about stability, not about how many equilibria there are.
    • \(p_1^*\) is an equilibrium, but we can’t say anything about its stability.
    • Not quite. Since \(\sigma^*\) is evolutionarily stable, Theorem 10.4 tells us that \(p_1^*\) is asymptotically stable.
    • \(p_1^*\) is a Nash equilibrium, but it is unstable.
    • Not quite. It is a Nash equilibrium, but Theorem 10.4 says it is asymptotically stable, since \(\sigma^*\) is evolutionarily stable.
    🔗
    Let’s finish by putting the theorems together.
    🔗

    Checkpoint 10.3.7.

    Which of the following statements are true? Select all that apply.
    🔗
    • If \(\sigma\) is an equilibrium of the replicator system, then \((\sigma, \sigma)\) is a Nash equilibrium.
    • False. This is only guaranteed when every strategy is active. Theorem 10.2 gives condition (1) of Theorem 5.2, but not condition (2). For example, the all-dove state in Hawks and Doves is an equilibrium, but it is not a Nash equilibrium, since a hawk would do better.
    • Every evolutionarily stable state is asymptotically stable.
    • True. This is Theorem 10.4.
    • If a population state is not evolutionarily stable, then it is not asymptotically stable.
    • False. This doesn’t follow from Theorem 10.4. The contrapositive of Theorem 10.4 is “if a state is not asymptotically stable, then it is not evolutionarily stable,” which is a different statement. For example, in the lizards game, \(\sigma^*\) is not evolutionarily stable, and Theorem 10.4 tells us nothing about its stability. (The analysis in Section 10.5 shows the population cycles around it, but that comes from a separate argument.)
    • For a game with two pure strategies (with \(a \neq c\) and \(b \neq d\)), a population state is asymptotically stable exactly when it is evolutionarily stable.
    • True. This is what we saw on the previous page: in all four cases, the stable equilibria are exactly the evolutionarily stable states.
    🔗
    Notice the difference between the first statement in this checkpoint and Checkpoint 10.3.2. In Checkpoint 10.3.2, every strategy was active, so there was nothing to check in condition (2) of Theorem 5.2! Here, \(\sigma\) could have inactive strategies.
