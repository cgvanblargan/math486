    Section 9.1 Autonomous Differential Equations and Equilibria

    In this chapter, we cover the parts of Chapter 9 of the book that are relevant to what we will be doing in the next chapter. You’re welcome to look at Chapter 9, but it goes into much more than we cover here, and more than we will need!
    🔗
    In Chapter 10, we will model populations whose makeup changes over time. To do that, we need differential equations, which are equations that relate an unknown function to its derivative. In this class, we will only look at one kind, called autonomous differential equations.
    🔗

    Definition 9.1.1 Autonomous Differential Equation.

    An autonomous differential equation is a differential equation of the form
    \begin{equation*} \frac{dp}{dt} = f(p), \end{equation*}
    where \(p = p(t)\) is an unknown function of time \(t\text{,}\) and the right side \(f(p)\) depends only on \(p\text{,}\) not on \(t\text{.}\)
    🔗
    🔗
    The book often writes \(\dot{p}\) for \(\frac{dp}{dt}\text{,}\) so the equation can also be written \(\dot{p} = f(p)\text{.}\) We will use both.
    🔗
    Here is the simplest example. Suppose a population grows at a rate proportional to its size, with proportionality constant 1. If \(p(t)\) is the size of the population at time \(t\text{,}\) this says
    \begin{equation*} \frac{dp}{dt} = p. \end{equation*}
    That is, a solution to this equation is a function \(p(t)\) whose derivative is equal to itself!
    🔗

    Checkpoint 9.1.2.

    Which famous function is equal to its own derivative?
    🔗
    • \(p(t) = e^t\)
    • Right! \(\frac{d}{dt}e^t = e^t\text{,}\) so \(p(t) = e^t\) is a solution of \(\frac{dp}{dt} = p\text{.}\)
    • \(p(t) = t^2\)
    • Not quite. The derivative of \(t^2\) is \(2t\text{,}\) which is not \(t^2\text{.}\)
    • \(p(t) = \ln t\)
    • Not quite. The derivative of \(\ln t\) is \(\frac{1}{t}\text{,}\) which is not \(\ln t\text{.}\)
    • \(p(t) = \sin t\)
    • Not quite. The derivative of \(\sin t\) is \(\cos t\text{,}\) which is not \(\sin t\text{.}\)
    🔗
    In fact, \(p(t) = Ce^t\) works for any constant \(C\text{,}\) since
    \begin{equation*} \frac{d}{dt}\left(Ce^t\right) = Ce^t. \end{equation*}
    Plugging in \(t = 0\) gives \(p(0) = Ce^0 = C\text{,}\) so the constant \(C\) is just the starting value of the population. Each choice of \(p(0)\) gives a different solution:
    🔗
    Mathematically, \(p\) can be any real number, including negative numbers. For a population, of course, only \(p \geq 0\) makes sense. (In Chapter 10, \(p\) will be a fraction of a population, so only \(0 \leq p \leq 1\) will matter.)
    🔗

    Definition 9.1.4 General and Particular Solutions.

    The general solution of a differential equation is a formula that describes all of its solutions, usually involving an arbitrary constant such as \(C\text{.}\)
    🔗
    A particular solution is one specific solution. It is usually determined by a starting value \(p(0)\text{,}\) called an initial condition.
    🔗
    🔗
    For example, \(p(t) = Ce^t\) is the general solution of \(\frac{dp}{dt} = p\text{,}\) and \(p(t) = 2e^t\) is the particular solution with \(p(0) = 2\text{.}\)
    🔗
    Now suppose the population grows at a rate proportional to its size, with proportionality constant 3:
    \begin{equation*} \frac{dp}{dt} = 3p. \end{equation*}
    A quick check shows that anything of the form \(p(t) = Ce^{3t}\) is a solution, since \(\frac{d}{dt}\left(Ce^{3t}\right) = 3Ce^{3t}\text{.}\) It turns out that these are all of the solutions, so \(p(t) = Ce^{3t}\) is the general solution. (The same is true for \(Ce^t\) above. We won’t prove that there are no other solutions.)
    🔗
    Notice that in both examples, setting \(C = 0\) gives \(p(t) = 0\text{,}\) a constant solution. If the population starts at \(p(0) = 0\text{,}\) it stays there forever! We will see that constant solutions like this turn out to be very important for understanding the behavior of all the other solutions. They are called equilibrium solutions.
    🔗

    Definition 9.1.5 Equilibrium Solution.

    A solution of \(\frac{dp}{dt} = f(p)\) of the form \(p(t) = k\) for some constant \(k\) is called an equilibrium solution. We often just call the number \(k\) an equilibrium.
    🔗
    🔗
    To find the equilibria, we don’t have to solve the differential equation at all. The following fact will be very useful for us!
    🔗

    Fact 9.1.6 Finding Equilibria.

    \(p(t) = k\) is an equilibrium solution of \(\frac{dp}{dt} = f(p)\) if and only if \(f(k) = 0\text{.}\)
    🔗
    🔗

    Justification.
    If \(p(t) = k\) is a solution, then \(f(k) = \frac{dp}{dt} = 0\text{,}\) since \(p\) is constant. Conversely, if \(f(k) = 0\text{,}\) then \(p(t) = k\) has \(\frac{dp}{dt} = 0 = f(k)\text{,}\) so it is a solution.
    🔗
    🔗
    In general, solving differential equations can be much more complicated than it was for something like \(\frac{dp}{dt} = 3p\text{.}\) Much of what we will be doing involves studying the behavior of solutions without actually solving the differential equation. In the example below, we find the equilibria using the fact above, instead of finding all the solutions and picking out the constant ones.
    🔗

    Example 9.1.7 Finding equilibria.

    Find the equilibrium solutions of \(\frac{dp}{dt} = (p - 2)(p + 3)\text{.}\)
    🔗
    Solution.
    Here \(f(p) = (p - 2)(p + 3)\text{.}\) Setting \(f(p) = 0\) gives \(p = 2\) or \(p = -3\text{,}\) so the equilibrium solutions are \(p(t) = 2\) and \(p(t) = -3\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 9.1.8.

    Which of the following are equilibrium solutions of \(\frac{dp}{dt} = p^2 - 1\text{?}\) Don’t forget to factor first! Select all that apply.
    🔗
    • \(p(t) = 1\)
    • Yes. \(p^2 - 1 = (p - 1)(p + 1)\text{,}\) and \(p = 1\) makes the first factor 0.
    • \(p(t) = 0\)
    • No. \(f(0) = 0^2 - 1 = -1\text{,}\) which is not 0.
    • \(p(t) = -1\)
    • Yes. \(p^2 - 1 = (p - 1)(p + 1)\text{,}\) and \(p = -1\) makes the second factor 0.
    • \(p(t) = 2\)
    • No. \(f(2) = 2^2 - 1 = 3\text{,}\) which is not 0.
